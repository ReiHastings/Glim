Implementation notes for Claude Code

This HTML file is a pixel-accurate mockup of the Glim home screen (companion mode). Open it in a browser to see the target layout. All measurements, colors, and SVG paths are the actual values to use in implementation.

Layout structure (top to bottom)

  • Background: Full-screen linear gradient (#0d1028 to #10103a to #150d32 to #0d0820) with scattered star dots (5 time-of-day colors) and mountain silhouette SVG at bottom
  • Glim creature: Large, centered, upper ~60% of screen. The actual OwlMoth component renders here. Width ~165px on mobile.
  • Speech bubble: Courier New, 10px, frosted glass style. Sits just below creature.
  • Summary widgets: 3-column grid just above nav bar. Each widget: rgba(255,255,255,0.06) bg, 12px border-radius, 1px border.
  • Nav bar: Persistent at bottom. rgba(255,255,255,0.06) bg, 14px border-radius. 5 items evenly spaced.

Summary widget specs

  • Steps: Progress ring (teal #5eead4), current count inside, "steps" label below. Ring fills through tier milestones (2.5k/5k/7.5k/10k). stroke-dasharray controls fill amount.
  • Water: Progress ring (blue #60a5fa), fraction inside (e.g. "5/8"), "water" label. Tapping opens water companion panel.
  • Tasks: Checkmark icon (purple #a78bfa) with "N done" count below. No fraction, just total completed today. Tapping opens to-do list focus screen.

Ring SVG technique: two overlapping circles. Background circle is the track (rgba(255,255,255,0.08)). Foreground circle has stroke-dasharray to show progress and transform="rotate(-90 cx cy)" to start from the top.

Nav bar specs

  • Order: home, focus, tasks, nutrition, more
  • Active color: rgba(200,210,230,0.8)
  • Inactive color: rgba(200,210,230,0.4)
  • Icon size: 18x18px SVGs
  • Label: 7px, same color as icon
  • All icons use currentColor so active/inactive is a single CSS color change on the parent div

Color reference

  • Glass surface: rgba(255,255,255,0.06)
  • Glass border: rgba(255,255,255,0.06-0.07)

  • Water accent: #60a5fa (blue)
  • Tasks accent: #a78bfa (purple)
  • Star colors: #86efac (green), #5eead4 (teal), #a5b4fc (periwinkle), #c4b5fd (lavender), #f9a8d4 (pink)

Companion panel behavior (not shown in mockup)

When a nav icon or widget is tapped, a panel slides up from the bottom (300ms ease-out) covering ~40% of screen height. Glim compresses to ~90% vertically. Drag handle at top to dismiss. Tap outside to dismiss. Only one panel open at a time.

See nav-icons-reference.md for React component structure and glim_project_documentation.Rmd Section 8.10 for full nav system spec.
